Panduan Penyelesaian Cepat

  • Pulihkan Paket Pro di Perangkat Baru: Pastikan Apple ID di iPhone sesuai dengan akun saat transaksi, lalu buka Profil → Tingkatkan ke Pro → Pulihkan Pembelian.
  • Kelola atau Batalkan Langganan Apple: Buka Pengaturan iPhone → Nama Apple ID Anda → Langganan atau klik tombol Kelola di App Store pada halaman penawaran Karirfy.
  • Pengingat Belajar Harian Tidak Muncul: Buka Pengaturan iOS → Karirfy → Pemberitahuan dan aktifkan Izinkan Pemberitahuan, lalu atur jadwal di halaman Profil.
  • Mulai dari Mode Tamu lalu Mendaftar Akun: Gunakan opsi Masuk / Daftar Akun melalui banner di halaman Profil untuk mengaitkan progres sesi Anda ke akun permanen.
  • Hapus Akun Permanen: Masuk ke aplikasi lalu pilih Profil → Hapus Akun Permanen. Lihat rincian retensi data pada halaman Kebijakan Privasi.
